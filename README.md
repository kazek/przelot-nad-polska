# Bird migration over Poland / Przelot nad Polską

Interactive map of night-time bird migration over Poland in autumn 2026, reconstructed from weather radars.

**Live map:** https://kazek.github.io/przelot-nad-polska/

Comments, bugs and ideas are welcome in [Issues](https://github.com/kazek/przelot-nad-polska/issues).

## What is here

This repository holds the published site only: `index.html`, one JSON file per night in `data/`, and rain frames in `rain/`. The method is described in the "For ornithologists" section of the page. Lines are a relative, modelled reconstruction, not bird counts or species data.

## Data sources

- Radar: [EUMETNET OPERA Open Radar Data](https://eumetnet.github.io/openradardata-documentation/), Polish POLRAD stations (IMGW-PIB), CC BY 4.0
- Rain: OPERA NIMBUS RATE composite, © EUMETNET, CC BY 4.0
- Weather: [Weather data by Open-Meteo.com](https://open-meteo.com/), CC BY 4.0
- Map: © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright)

The data have been processed. The results are our own analysis and do not come from the data providers, who are not responsible for them.
